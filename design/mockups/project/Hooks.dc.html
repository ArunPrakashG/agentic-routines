Code written by someone elseHooks run on events while this routine replays. They run in a sandbox with no network, and can only ask the extension to skip a step, fill a value, click, type, wait, go to a page on this site, leave a note, stop or pause. They cannot approve a pause.
Off until you allow them. If the code changes, you are asked again.
step.before
if (!ctx.step || ctx.step.action !== 'type') return;
const m = /Suggested name: <b[^>]*>([^<]+)</.exec(ctx.dom.html);
return m ? [{ do: 'set', value: m[1] }] : [];
step.after
if (ctx.step.action !== 'click') return;
return { do: 'note', text: 'Saved at ' + ctx.url };
run.end
return { do: 'note', text: 'Done on ' + ctx.url };
