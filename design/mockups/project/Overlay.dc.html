Type · Release notes

Edge glow

Accent light, 56px deep, along all four edges of the page. Fades in over 400ms when a step starts, breathes slowly while steps run, fades out when it ends. Turns amber at a pause. Never takes pointer events.

Cursor

An accent arrow with a small label naming the action (Click, Type, Select). It glides to the element in 250 to 600ms depending on distance, and clicks with a ring that expands and fades.

Target

The element gets a 2px accent outline and a faint fill just before the cursor lands, so the eye is already there. It fades 300ms after the action.

States

Running · accent glow, cursor follows each step
Paused before a final step · amber glow, no cursor
Changed step · the target outline turns red until resolved

Rules

  • Hidden for every screenshot, so a replay check never sees it.
  • Reduced motion: glow and outline stay, the cursor jumps with no travel.
  • Lives in a shadow root on the page, above everything, ignores the mouse.
  • Off when the run ends, the tab closes or the agent disconnects.
